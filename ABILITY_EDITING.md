# Delve Deep - Editing Classes, Spells, and Abilities

Most class tuning lives in one file:

- `data/classes.js`

Enemy and boss abilities live in:

- `data/enemies.js`

The combat code that decides when and how abilities are used lives in:

- `scenes/BattleScene.js`

## Changing an existing class ability

Open `data/classes.js`, find the class, then find its `abilities` block.

Example:

```js
Wizard: {
  maxMana: 120,
  manaRegen: 8,
  abilities: {
    primary: {
      name: 'Fireball',
      cooldown: 4200,
      windup: 760,
      power: 34,
      radius: 125,
      aoe: true,
      manaCost: 28
    }
  }
}
```

The common fields are:

- `name`: text shown in combat.
- `cooldown`: milliseconds before the ability can be used again.
- `windup`: cast/attack time in milliseconds.
- `power`: base damage or healing.
- `manaCost`: mana spent when the ability is used.
- `radius`: size of an area effect.
- `aoe: true`: tells the normal damage logic that the ability affects an area.
- `duration`: how long a buff/debuff lasts.
- `healthCost`: percentage of the caster's max HP spent to use the ability. `0.06` means 6%.
- `threatMultiplier`: extra or reduced threat generated by the ability.

Class-level mana fields are:

```js
maxMana: 120,
manaRegen: 8,
basicHealManaCost: 8
```

`manaRegen` is mana restored per second during combat.

## Adding a normal damage spell

If the class already uses a normal `primary`, `secondary`, or `close` damage ability, add or edit that ability in `data/classes.js` and then make sure `scenes/BattleScene.js` calls that key from the class's update function.

Examples are in:

- `updateTankUnit()`
- `updateMeleeUnit()`
- `updateRangedUnit()`

`beginDamageAbility()` handles normal single-target abilities.

`beginAoeDamageAbility()` handles normal area-damage abilities.

## Adding a healing spell

Add the ability to the healer's `abilities` block in `data/classes.js`.

Then use one of these helpers in `scenes/BattleScene.js`:

- `beginHealAbility()` for a single-target heal.
- `beginMultiHeal()` for a heal that selects several injured party members.

The healer AI is in `updateHealerUnit()`.

## Adding a special utility ability

Special abilities such as Protective Shield, Sand Kick, War Roar, Arcane Shield, Hunter's Mark, and Blood Curse are handled in:

- `BattleScene.tryClassUtility()`

Add the data to `data/classes.js`, then add the behavior for the class in `tryClassUtility()`.

Use `unit.markAbilityUsed('utility', time)` after the ability successfully starts. This starts its cooldown and automatically spends its configured `manaCost`.

## Floating ability announcements

Named abilities are announced automatically by the normal damage/heal helpers.

For a custom ability, call:

```js
this.announceAbility(unit, 'Ability Name', '#93c5fd');
```

The color is optional.

## Adding or changing enemy abilities

Open `data/enemies.js`.

Enemies currently understand two standard ability styles:

- `primary` with `telegraph`, `radius`, and `power`: ground-area attack.
- `secondary` with `windup` and `power`: targeted ranged attack.

Example:

```js
primary: {
  name: 'Abyssal Collapse',
  cooldown: 5200,
  telegraph: 1450,
  radius: 190,
  power: 34
}
```

Void Portal encounter groups are in `voidPortalWaves` in the same file.

## Adding a brand-new class

1. Add a new entry to `CLASS_DEFINITIONS` in `data/classes.js`.
2. Give it a `role`, stats, description, and abilities.
3. Add an adventurer using that class in `data/adventurers.js` if you want one available immediately.
4. If the class needs behavior that is different from the existing Tank, Healer, Melee DPS, or Ranged DPS logic, add that behavior to `scenes/BattleScene.js`.

For simple classes, copying the closest existing class and changing its numbers/ability names is the fastest path.
