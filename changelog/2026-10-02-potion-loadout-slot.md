# Potion loadout slot

- Added a fourth character slot for a potion pack with one type and up to three uses. It persists with character equipment and does not grant passive stats.
- Added the potion picker to the Adventurer's Hall character sheet and a Potions category to the Items inventory. Empty states remain until potion definitions are added.
- Kept the current shared Healing Tonic from Prepared Supplies. Character potion consumption and effects will follow when potion types are defined.
- Recorded the agreed item progression direction in the game design document. Exact drop odds, Void loot tables, recipes, and scroll duration remain to be decided.
