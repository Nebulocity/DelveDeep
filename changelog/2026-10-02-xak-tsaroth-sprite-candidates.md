# Xak Tsaroth creature sprite candidates

- Researched the original post-Cataclysm *DL1: Dragons of Despair* ruin, immediate swamp, fixed encounters and random encounters.
- Generated five 128 x 128 transparent PixelLab candidates for each of 13 creature types, for 65 standalone sprites.
- Added a contact sheet and a small rebuild script for comparison. The candidate PNGs are selection art only and are not wired into combat data or animation sheets.
- Kept the source-based roster and visual reference links in `assets/enemies/xak-tsaroth/README.md` and PixelLab generation IDs in `pixellab-jobs.json`.
- Validated that the preview builds from all 65 files and that `npm run build` passes. Android presentation has not been evaluated because the art is not yet integrated.
