# The Vibrant Tear

- Added a new Void Portal map location on a grassy wilderness knoll. It becomes available after reaching Duskfall and clearing Thornbriar Hollow, including for existing saves that already discovered Duskfall.
- Added a distinct pixel-art battle background and a smaller set of void motes, clouds, and lightning.
- Authored four dangerous void waves ending with the Abyssal Sovereign. The shorter encounter represents the portal's newer, incomplete state.
- Reused the existing Void Portal enemy, battle, reward, and save systems.
