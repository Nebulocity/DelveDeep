# Blender pipeline

The Slime Cave is the current Blender environment integration. Its local authoring source is `assets/blender/the_slime_cave/the_slime_cave_game_export_v1.blend`. `Scene` is the full scene; `DD_Export` contains export view layers. The production camera is named `CAM_SlimeCave_Game`. Preserve its framing and depth of field. A separate chat is checking its exact measurements; record verified values here after that work finishes.

The source `.blend` and source ambient movie are local and not recoverable from a Git clone. Maintain a separate backup. The checked-in game-facing exports are under `assets/environments/slime-cave/`. `assets/blender/the_slime_cave/export_phaser_stills.py` renders the static layers without saving scene changes. The existing ambient source is a 240-frame, 24 fps loop cropped to the bottom 1920 x 540 region, then masked around pools in Phaser. Do not re-render or change the production camera merely to adjust game layout.

`data/levels/SlimeCave.js` declares 1920 x 1080 camera-space art, a 120-pixel upward offset, floor corners, layer URLs and ambient mask regions. `combat/LayeredEnvironment.js` fits and projects those layers into the 2400 x 1080 game canvas. The static reference covers gaps while video loads; background, battlefield, ambient patches, gameplay, foreground and UI appear in depth order. The exact export command and local-source caveats are in the [source README](../assets/blender/the_slime_cave/README.md). A final in-game review should check alignment, mask edges, occlusion and Android video playback.
